
A **Success Target** is the number a character must roll equal to or below to succeed on a test.

Most tests combine two [[Attributes|Attributes]] and one Skill:

**Success Target = Attribute + Attribute + Skill**

If no Skill applies, make an [[Skills#Attribute Checks|Attribute Check]] instead. Add the two relevant Attributes together, then multiply the result by 2.

**Success Target = (Attribute + Attribute) × 2**

If one Attribute clearly applies to both sides of the test, use it twice.

Apply all relevant [[Modifiers|modifiers]] before rolling. A Success Target can never be lower than 5 or higher than 150.

Success Targets above 100 are valid. The test still fails on a roll of 96–00, but higher Success Targets can generate more Hits when the roll succeeds.

## Hits

A successful test answers whether the action works. **Hits** measure how well it works when the degree of success matters.

To calculate Hits, ignore the units digit of the d100 result and the Success Target, then subtract the roll value from the target value.

For example, a roll of 34 against a Success Target of 65 compares 3 to 6, generating 3 Hits. The same roll against a Success Target of 42 generates 1 Hit.

Failed tests can generate negative Hits when the degree of failure matters. A roll of 78 against a Success Target of 65 generates −1 Hit.

Automatic failures from a roll of 96–00 can never generate positive Hits.

Many tests do not require Hits at all. If the only question is whether the character succeeds or fails, resolve the test from the d100 result and continue.

## Outcomes

When the degree of success or failure matters, use the number of Hits to interpret the result.

| Hits | Successful Test | Failed Test |
|---|---|---|
| 6 or more | Exceptional Success | |
| 4 to 5 | Major Success | |
| 2 to 3 | Strong Success | |
| 0 to 1 | Narrow Success | Narrow Failure |
| −1 | | Narrow Failure |
| −2 to −3 | | Strong Failure |
| −4 to −5 | | Major Failure |
| −6 or less | | Exceptional Failure |

The Outcomes table is a guide for situations where the quality of the result matters. Specific rules may use Hits directly instead.
