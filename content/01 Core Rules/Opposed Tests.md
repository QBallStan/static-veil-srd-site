Use an **Opposed Test** when two characters compete directly and the result depends on who does better.

Both sides make a test. They don't need to use the same [[Attributes|Attribute]] or Skill, as long as each one fits how that character is going about it.

- If only one side succeeds, that side wins.
- If both succeed, the side with more [[Success Targets and Hits#Hits|Hits]] wins.
- If both succeed with the same number of Hits, it's a tie. When one side is trying to overcome the other's resistance, a tie goes to the side resisting.
- If both fail, nobody wins and the situation usually stays as it was.

## Net Hits

When the size of the win matters, subtract the loser's Hits from the winner's. The difference is the winner's **Net Hits**. A side whose test failed counts as 0 Hits. Some other rules use Net Hits as well.

## Complications

Resolve [[Complications]] after you know who won. A Complication doesn't change the winner or anyone's Hits, so a character can win the contest and still suffer one.
