[[Weapons#Firearms|Firearms]] can be modified: their mechanism, handling, electronics and accessories. Every firearm has a **Frame**, which decides which mod **slots** it has. Each slot holds one mod.

| Frame | Internal | Top | Bottom | Muzzle | Stock |
|---|:---:|:---:|:---:|:---:|:---:|
| **Small**: holdouts and other compact guns | ✓ | | | | |
| **Handgun**: pistols, revolvers, machine pistols | ✓ | ✓ | ✓ | ✓ | |
| **Full-Size**: SMGs, shotguns, rifles, machine guns | ✓ | ✓ | ✓ | ✓ | ✓ |

A firearm's own entry can change its Frame if the way it's built calls for it.

## Slots

- **Internal:** the mechanism, electronics, feed or fire control.
- **Top:** optics: scopes, reflex sights, thermal or smart optics, rangefinders.
- **Bottom:** underbarrel and side accessories: flashlights, lasers, foregrips, bipods, secondary weapons.
- **Muzzle:** suppressors, compensators, muzzle brakes, flash hiders.
- **Stock:** folding, adjustable, precision or recoil-reducing stocks.

A mod takes one slot. To put a new one in an occupied slot, take the old one out first.

Having a free slot doesn't mean a mod fits. Each mod lists what it needs: a particular Frame, automatic fire, a detachable magazine, a compatible feed and so on.

Cosmetic changes such as paint, engraving, decals or grip wrap don't use a slot. Anything that gives a real mechanical benefit is a mod, and takes one.

## Installing and Removing

The GM decides how long it takes to install or remove a mod: a few minutes to swap a sight, a few hours or a full day for serious work (see [[Time and Extended Tests#Time Die|Time Die]]). A **simple** mod just takes the time, with no test. A mod that changes the mechanism, the electronics, the feed or the structure of the gun needs an **[[Skills#Expertise Skills|Armorer]]** test. On a failure, the installation doesn't work, and the time is lost. A [[Complications|Complication]] can damage parts, throw the calibration off or damage the gun itself.
